Linux • Networking • Cyber // //

LINUX // リナックス

Terminal & Core Navigation[CORE CLI]

Navigasi berkas, manipulasi teks (`grep`, `awk`, `sed`), dan manajemen proses (`ps`, `top`, `kill`).

Permissions & Ownership (chmod/chown)[SECURITY]

Struktur permission octal vs symbolic, SUID, SGID, dan Sticky Bit untuk privilege management.

SSH Hardening & Key Authentication[DEFENSE]

Konfigurasi `/etc/ssh/sshd_config`, nonaktifkan root login, serta implementasi key pair Ed25519.

NETWORKING // ネットワーク

IP Addressing, CIDR & Subnetting[FOUNDATION]

Kalkulasi subnet mask (/24, /27), alokasi IP privat (RFC 1918), dan hierarki broadcast address.

DNS, DHCP & Transport Protocols[PROTOCOLS]

Alur 3-way handshake TCP vs UDP, DNS query resolving (A, PTR, CNAME), dan penyewaan IP DHCP (DORA).

SECURITY // セキュリティ

CIA Triad & Threat Modeling[FRAMEWORK]

Pilar Confidentiality, Integrity, Availability serta dasar klasifikasi risiko aset organisasi.

OWASP Top 10 Essentials[WEB APP]

Analisis kerentanan Broken Access Control, Injection, Cryptographic Failures, dan Security Misconfiguration.

Log Analysis & SIEM Fundamentals[BLUE TEAM]

Teknik parsing `/var/log/auth.log` dan event logs untuk deteksi aktivitas lateral movement.
