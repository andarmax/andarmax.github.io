SSH Hardening & Key Authentication

Catatan implementasi pengamanan port SSH pada Linux server untuk mencegah brute-force attacks dan akses unauthorised pengguna root.

1. Generate SSH Key Pair

Gunakan algoritma Ed25519 yang lebih ringkas dan kuat dibanding RSA konvensional:

ssh-keygen -t ed25519 -C "admin@andarmax.box"

2. Konfigurasi /etc/ssh/sshd_config

Buka berkas konfigurasi daemon SSH dan sesuaikan parameter berikut:

# Nonaktifkan autentikasi root langsung
PermitRootLogin no

# Paksa hanya memakai public key (matikan password prompt)
PasswordAuthentication no
PubkeyAuthentication yes

# Batasi maksimal percobaan login
MaxAuthTries 3

3. Restart Service & Verifikasi

Terapkan konfigurasi baru tanpa memutus sesi terminal yang sedang aktif:

sudo systemctl restart sshd
